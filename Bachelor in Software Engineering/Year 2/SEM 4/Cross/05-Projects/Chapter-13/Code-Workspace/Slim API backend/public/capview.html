📱 Capacitor Configuration — UTM Books

Wraps the Vue 3 production build (dist/) into a native Android app
appId: com.utm.books appName: UTM Books webDir: dist platform: Android (emulator)
📄 frontend/capacitor.config.json
{
  "appId":   "com.utm.books",
  "appName": "UTM Books",
  "webDir":  "dist",
  "server": {
    "androidScheme": "https"
  }
}
The same Vue dist/ served on the web is synced into the Android project via npx cap sync android · SCSM2223 Chapter 13
