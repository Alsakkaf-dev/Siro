# سجلات راشد اليومية (Mohammed's daily logs)
One row per day (food: one row per meal). Unknown = empty, never 0. Filled from the nightly 9:45 PM check-in.
- prayers.csv : each prayer = on_time / late / missed
- sleep.csv : bedtime (target 10:30 PM), wake time
- vape.csv : plan day N (cut 20 min/day from 2026-10-18), kept limit y/n
- tea.csv : sugar plan 70-3g/day from 2026-10-18, actual
- water.csv : litres (target 3 L)
- food.csv : meals, kcal/protein estimates (target 1500 kcal, ~120 g protein)
- workouts.csv : A/B, walk laps (365 m), swim minutes
- body.csv : weekly weight (Friday). Monthly waist CANCELLED (D-R-020, 2026-10-21) — never ask; waist_cm column kept for history only
- daily_mood.csv : energy/mood 1-5 (optional)
- daily_summary.csv : one-line rollup per day for monthly stats
