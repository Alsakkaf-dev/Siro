# المساعد الذكي — دليل التشغيل والاستخدام

## ما هو؟
موديل ذكاء اصطناعي يعمل في قلب المنصة. تطلب منه بجملة، فيبحث ويضيف ويعدّل ويحسب ويلخّص في كل الخطوط: الدراسة، المكتبة، مساحاتي، الحياة، والرياضة.

ضماناته:
- **كل فعل يمر بنفس قواعد الموقع.** نفس التحقق، ويُسجَّل في سجل النشاط باسم «المساعد»، ويمكن التراجع عنه.
- **أنت المتحكم.** التعديل يظهر لك معاينةً أولًا (أو يُنفَّذ مباشرة مع زر تراجع إن اخترت ذلك)، والحذف يطلب تأكيدك دائمًا.
- **ممنوع عليه تمامًا:** استعادة النسخ الاحتياطية، والاستيراد الذي يكتب فوق بياناتك، والإعدادات والمفاتيح. ولا يكتب في السجل: يكتب مسودات فقط، والنظام هو من ينفّذها.
- **لا تخمين:** أي وزن أو تاريخ لم تذكره يُترك «غير معروف».

## التشغيل على جهازك (مجاني بالكامل)
1. ثبّت **Ollama** من ollama.com وشغّله.
2. نزّل الموديل المناسب لذاكرة جهازك (الموقع يكشفها ويقترح عليك في الإعدادات ← الذكاء):

   | ذاكرة الجهاز | الموديل | الأمر |
   |---|---|---|
   | أقل من 8GB | Qwen3.5 2B | `ollama pull qwen3.5:2b` |
   | 8GB | **Qwen3.5 4B (الافتراضي)** | `ollama pull qwen3.5:4b` |
   | 16GB أو أكثر، أو كرت شاشة 8GB | Qwen3.5 9B | `ollama pull qwen3.5:9b` |

   إن كان عندك Qwen مثبّت مسبقًا (مثل qwen2.5:3b) فسيُستخدم تلقائيًا، ولا حاجة لتنزيل شيء.
3. شغّل الموقع (`start.bat`) واضغط **Ctrl+J**.

## النسخة الأونلاين (Vercel)
- **أسرع طريق:** مزوّد سحابي بمفتاح. ضع في متغيرات Vercel:
  - `AI_BASE_URL` و`AI_MODEL` و`AI_API_KEY`، وأي مزوّد OpenAI-compatible يصلح. مثال OpenRouter: `https://openrouter.ai/api/v1` مع موديل Qwen ينتهي بـ `:free`.
  - `AI_ACCESS_KEY`: رمز سري تختاره أنت، وتدخله مرة واحدة في المتصفح. **بدونه يبقى الذكاء مقفلًا** حتى لا يستهلك أحد مفاتيحك.
- **أو Qwen حاسوبك نفسه من الموقع الأونلاين:**
  1. فعّل مزوّد «Qwen على حاسوبي (من المتصفح)» في الإعدادات.
  2. نفّذ مرة واحدة: `setx OLLAMA_ORIGINS "https://siro-platform.vercel.app"`
  3. أعد تشغيل Ollama.

## المدفوع (اختياري — آخر خيار في السلسلة)
- الإعدادات ← الذكاء ← «Claude (Anthropic)»: الصق المفتاح واختر الموديل:
  - `claude-opus-5-5`: الأقوى.
  - `claude-sonnet-5-5`: المتوازن.
  - `claude-haiku-5-5`: الأسرع والأرخص.
- أو «مزوّد مدفوع (OpenAI-compatible)» لأي مزوّد آخر.
- على Vercel: `ANTHROPIC_API_KEY`.
- **سقف يومي للتوكنات** يحميك من أي فاتورة مفاجئة. موجز الخلفية لا يستخدم المدفوع أبدًا.
- **الترتيب = السلسلة الاحتياطية.** يُجرَّب الأول؛ وإن فشل قبل أن يكتب شيئًا ينتقل للتالي تلقائيًا.

## أين تجده؟
| المكان | ماذا يفعل |
|---|---|
| **Ctrl+J** أو زر ✦ في الشريط العلوي | المساعد الجانبي، يعرف الصفحة التي أنت فيها |
| شريط البحث `/` | اكتب جملة ← «اطلب من المساعد» (أو Ctrl+Enter) |
| زر «إنشاء» | «اطلب بجملة» و«التقاط ذكي»: الصق خطة مادة فتُضاف تقييماتها دفعة واحدة |
| الرئيسية | «موجز اليوم» |
| صفحة المادة | «حلّل وضعي» و«التقاط ذكي» |
| ملف في المكتبة | «لخّص» و«اختبرني» |
| مساحاتي | «صمّمها بالذكاء»: صف ما تريد تتبعه فتُبنى الحقول والحالات |
| داخل مساحة / الأتمتة | «اطلب بالذكاء» و«اكتبها بالعربي» |
| الحياة ← مسودات الأوامر | «سجّل بجملة»: «صليت الفجر في وقتها»، «صرفت 12 رنجت» |
| الوارد | «موجز اليوم» تلقائيًا كل صباح (نسخة الجهاز، مجاني فقط) |
| سجل النشاط | كل ما فعله المساعد موسوم «بواسطة المساعد» |

## قياس أي موديل على جهازك
```
npm run ai:eval            # كل الأدوات
npm run ai:eval -- --small # كما يراه موديل صغير (أدوات موجّهة)
```
يعطيك: هل اختار الأداة الصحيحة بالوسائط الصحيحة لـ 30 أمرًا عربيًا حقيقيًا، ومتوسط الزمن. لا يغيّر أي بيانات.
