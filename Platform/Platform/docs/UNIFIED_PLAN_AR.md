## بروتوكول التشغيل (ثابت)
1. **لا يبدأ تنفيذ قبل كلمة «إبدأ» من محمد.** التجهيز والتوحيد (هذه الوثيقة) منجزان قبلها.
2. بعد «إبدأ» تُنفَّذ المرحلة 1. عند اكتمالها بالكامل (البوابات خضراء + commit + push + تحديث الحالة) أكتب: **«أكملت المرحلة N»** وأتوقف.
3. لا أنتقل إلا حين يكتب محمد **«أكمل المرحلة N+1»**.
4. بعد «أكمل المرحلة 4» لا يُقبل ردّ «أكملت» وحده: يجب أن يكون **كل شيء في الخطتين منفّذًا فعليًا ومتحققًا منه** (دليله في تقرير ختامي).
5. بوابات كل مرحلة: `typecheck` نظيف · `vitest` أخضر مع اختبارات للجديد · `npm run build` · `npm run smoke` · `browser-smoke --strict` (1280/390) بلا أخطاء · لا انحدار في أي منصة موجودة (N-07) · `git status` نظيف خارج المقصود · commit مستقل لكل مرحلة (وفرعية عند الحاجة) + push · تحديث جدول الحالة أدناه.
6. نسخة العمل خارج المستودع (`scripts/dev/sync-to-scratch.sh`)، ولا `npm` داخل المستودع. لا ارتكاب `dist/` ولا `node_modules/` ولا `data/*.db*` ولا `backups/` ولا `*.log`.

- ممنوعات المطبخ N-01…N-16 سارية: 26 مكوّنًا فقط، لا تخسيس/TDEE، لا أسعار مؤكدة بلا مصدر، قانون السعرات 1200–1500 لا يُمسّ (G-05)، لا كتابة في Outlook بلا اقتراح و«رن» منفصلة (G-03)، أرقام 0-9، لا تعديل الوصفات الـ12 الأصلية في مكانها.
