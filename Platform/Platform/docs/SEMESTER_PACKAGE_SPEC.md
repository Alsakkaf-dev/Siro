# حزمة الفصل — Semester Package v1

كل فصل منتهٍ يُحفظ في Google Drive داخل مجلد واحد باسم `SEM-X`. الموقع يستورد هذا المجلد (صفحة «استيراد فصل») ويملأ منه: الفصل، المواد، التقييمات، الملاحظات، النتائج الرسمية، وملفات المكتبة.
القاعدة: **لا تخمين**. أي شيء لا يطابق الصيغة يظهر في تقرير الفحص؛ الأخطاء تمنع الاستيراد، والتحذيرات لا تمنعه.

## الشكل

```
SEM-5/                                   ← الاسم بالضبط: SEM-رقم
├── semester.json                        ← إلزامي
├── 00-General/                          ← ملفات عامة للفصل (جداول، تعاميم، سجلات التسجيل والنتائج)
├── SCSE3103-05 Cognitive Computing/     ← مجلد لكل مادة: «الرمز-الشعبة الاسم»
│   ├── 01-Course-Information/           → توصيف المادة
│   ├── 02-Lectures/                     → محاضرة
│   ├── 03-Labs/                         → مختبر
│   ├── 04-Assignments/                  → واجب
│   ├── 05-Projects/                     → مشروع
│   ├── 06-Exams/                        → امتحان / كويز
│   ├── 07-Study-Notes/                  → ملخص
│   ├── 08-Recordings/                   → تسجيلات
│   ├── 09-Tutorials/                    → تمارين
│   ├── 10-References/                   → كتب ومراجع
│   └── 99-Other/                        → أي شيء آخر
└── …
```

- الترقيم 01–08 هو نفس ترقيمك الحالي في SEM 5؛ 09 و10 و99 إضافات.
- داخل كل تصنيف يُسمح بمجلدات فرعية بأي اسم (مثل `05-Projects/P1/Answer/`).
- مجلد المادة يبدأ برمز المادة (4 حروف + 4 أرقام). الشعبة والاسم اختياريان: `UHLB2122` صحيح.

## semester.json

نفس صيغة بذرة الموقع (`seed/sem5-dashboard.json`) مع رقم الإصدار:

```json
{
  "package_version": 1,
  "source": "package:SEM-1",
  "semester": { "id": "sem1", "code": "SEM 1", "name": "Semester I 2024/2025", "year_no": 1, "sem_no": 1,
                "start_date": "2024-10-06", "weeks": 16, "break_weeks": [], "exam_start": null, "exam_end": null, "note": "…" },
  "courses": [
    { "id": "sem1-dg", "code": "SCSR1013", "name": "Digital Logic", "section": "01", "credits": 3, "color": "#4CC9F0",
      "result": { "grade": "C+", "points": 2.33, "credits": 3, "status": null } }
  ],
  "assessments": [],
  "notes": []
}
```

- `result` اختياري: النتيجة الرسمية من كشف الدرجات.
- `sem_no` يجب أن يطابق رقم المجلد (`SEM-1` ↔ `1`).
- كل مادة في `courses` يجب أن يكون لها مجلد (وإلا تحذير)، وكل مجلد مادة يجب أن يكون رمزه في `courses` (وإلا خطأ).

## الفحص

| المستوى | الحالة |
|---|---|
| خطأ | `semester.json` مفقود أو غير صالح؛ اسم المجلد ليس `SEM-رقم`؛ `sem_no` لا يطابق؛ مجلد في الجذر ليس `00-General` ولا مجلد مادة؛ رمز مادة غير موجود في `semester.json`؛ تصنيف غير معروف داخل مادة؛ مجلدان لنفس المادة |
| تحذير | ملف في جذر الحزمة؛ ملف مباشرة داخل مجلد المادة (يُعامل `99-Other`)؛ مادة بلا مجلد؛ ملفات مخفية |

## الاستيراد

- قبل التطبيق: نسخة احتياطية تلقائية (`pre-package`).
- البيانات تُدمج (merge) بالمعرّفات؛ لا يُحذف شيء من بياناتك.
- الملفات: إعادة استيراد نفس الحزمة تستبدل فهرس ملفاتها فقط (ملف حُذف من الحزمة يختفي من المكتبة، ولا تكرار). الوسوم والملاحظات والتقدّم تبقى لأن المرجع ثابت.
- المصادر: رابط مجلد Drive عام (يحتاج `PLATFORM_DRIVE_API_KEY`)، مجلد محلي (نسخة الجهاز فقط)، أو قائمة الحزمة (`*.listing.json`) التي تنتجها أداة الرفع.

## نهاية كل فصل

1. رتّب مجلد الفصل بهذه الصيغة (أو اطلب من المساعد تشغيل المحوّل `scripts/package-semester.mjs`).
2. ارفعه إلى `Siro Semesters/SEM-X` في Google Drive.
3. في الموقع: الفصول ← استيراد فصل ← الصق رابط المجلد ← فحص ← استيراد.
