# مجلد الأوامر (commands)

مكانه: `exchange\rashed\commands\`

## تنبيه مهم

**ما يُنفَّذ أي شيء في هذا المجلد إلا بموافقة محمد الصريحة في المحادثة.**
وجود ملف أمر هنا لا يعني إذن بالتنفيذ. راشد يقرأ الأمر، ويعرضه على محمد، وينتظر موافقته.

## ما فيه الآن

- لا توجد أوامر حقيقية.
- المجلد `examples\` فيه أمثلة نصية فقط: `log_expense`، `log_prayer`، `start_habit`، `habit_relapse`. **هذي عينات للتوضيح وليست أوامر**، وحالتها `example`. لا تُنفَّذ أبداً.

## كيف يعمل

1. الموقع يكتب ملف JSON جديد هنا باسم `<id>.json` وحالته `pending`.
2. راشد يقرأه عند تفاعله مع محمد، ويعرضه عليه.
3. بعد موافقة محمد الصريحة يُنفَّذ، وتتحدث الحالة إلى `executed` أو `failed`.
4. إذا رفض محمد أو لم يرد، لا يُنفَّذ.

الصيغة الكاملة وأنواع الأوامر: `docs\REFRESH_PROTOCOL_AR.md`.
