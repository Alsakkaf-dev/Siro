# تقرير البناء والترحيل
الحالة الحالية: الحزمة بُنيت؛ النقل النهائي والفحص قيد التنفيذ. النتيجة النهائية ستظهر في migration-result.json بعد التحقق.

## النطاق
ثلاثة بوتات: سالي وراشد وفارس، بأسماء بشرية عربية وشخصيات خيالية وصور مستقلة.
ملفات تعليمات ودستور وصلاحيات ووحدات عمل وذاكرة حالية وتاريخية ورسائل تشغيل وصفحة HOME محلية.
الصور أنشئت بالأداة المدمجة image_gen؛ وصف كل صورة في AVATAR_PROMPT.txt بجوارها، والأصل النهائي avatar.png.

## القراءة والمراجعة
تمت مراجعة أدوار BOOT السبعة والبروتوكول المشترك وSTART، وفروق النسخة الاحتياطية8ملفات، وملفات STATE النصية8ملفات، والنص المرفق.
استخدمت مهارة system-design لتنظيم الاختصاصات، وimagegen للشخصيات. استُخدم مسار PDF المحلي لقراءة خطة الدراسة بعد تعذر وجود أدوات Adobe المتخصصة.
الجدول XLSX حُفظ بايتًا ببايت، دون إعادة بناء أو تدقيق كامل للخلايا.
المكتبة الأكاديمية والمشاريع: جرد وحفظ ونقل بنية؛ لم تتم قراءة كل صفحة أو تدقيق كل كود أو فتح كل ملف ثنائي. لا ندعي خلاف ذلك.

## الحفظ
نسخة استرجاع25ملفًا في legacy-controls.zip، مع SHA-256 في control-manifest.json. طوبقت محتويات ZIP مع الأصل قبل الحذف.
المراجع اللازمة نسخت إلى REFERENCES الخاصة بكل بوت دون تغيير النص الأصلي؛ لا تعليمات قديمة نشطة في الحالة الجديدة.
المكتبة نُقلت كمجلدات كاملة على القرص نفسه؛ لا تغييرات محتوى. library-before.csv سجل المسارات والأحجام والتوقيت قبل النقل، وlibrary-summary.json ملخصها. التحقق اللاحق يسجل النتيجة.
فحص المكتبة مقارنة مسارات وأحجام وmtime؛ ليس SHA-256 شاملًا لحوالي29.5GB. SHA-256 الكامل يخص ملفات البوتات25والنسخ المرجعية والصور والحزمة، لا كل مصادر المكتبة.

## ما سيُحذف من المواقع القديمة بعد نجاح الفحص
BOOT وSTATE وBackups فقط بعد التحقق من تغطية كل ملف بالأرشيف؛ لا مصادر أكاديمية أو مشاريع تحذف.
بقية مجلدات الجذر تنتقل إلى Library، ويصبح Grok Boot الوحيد في UTM.
أي ملفات أو مسارات أضيفت أو تغيرت بعد الجرد توقف حذف مجلدها حتى يُراجع الفرق.
انتقال المجلدات قد يؤثر في اختصارات أو برامج تعتمد المسار المطلق القديم؛ لم تُعدّل شيفرات المشاريع أو إعداداتها لتخمين بديل.

## حدود التشغيل
لم ننشئ البوتات أو نختبر Grok أو نربط البريد أو التقويم أو مهام دورية. CAPABILITIES يبدأ unknown.
لا جلب لبريد حقيقي ولا إرسال ولا دفع ولا تسجيل مواد ولا تشغيل مشاريع عند البناء.
تاريخ الحالة القديمة محفوظ؛ المراجعة الحالية تسوي التعارضات ولا تؤكد لوائح أو سياسة أو سعرًا من جهة خارجية.
## الاسترجاع
للرجوع إلى ملف قديم: افتح legacy-controls.zip، واستخرج الملف المطلوب إلى مجلد مراجعة جديد داخل90_Migration، ثم قارن البصمة بالmanifest. لا تستخرج فوق STATE الجديد أو تشغّل تعليمات BOOT القديمة تلقائيًا.
الأرشيف قد يتضمن بيانات شخصية؛ لا ترفعه لخدمة خارجية بلا حاجة وتفويض.
## الأدوات المساندة
prepare_migration.py ملف عملية واحدة تحضيرية، وليس أداة تشغيل يومية؛ لا تعِد تشغيله بعد النقل. validate_package.py للقراءة والتحقق. النصوص لا تمنح البوت صلاحية حذف أو نقل جديدة.
